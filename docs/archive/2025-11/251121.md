# division-boxes component

create an angular component that visualizes this process, step by step. 
animate the red line division over the top of the preceding step that moves left-to-right on lat division and top-to-bottom on log division (similar to existing red line animation on /map page), then once the red line animation is complete draw the newly divided boxes showing district group (DG) size. 

component visualization has the same grid layout (as image) starting with single box on top row with number of districts, then when user clicks next, the 1st division box is animated over the top of the of the previous step box which was copied and used as starting point in position of next step district group box. the user clicks next again and the component repeats the same progression in the next grid spot. this continues until last step shows entire state divided into single geodistricts. 

note that when a district group only contains one district (i.e. becomes a geodistrict) then is becomes green. 

also note the text label (for number of districts in each DG) scales with the size of container, that is font-size reduces as size of DG box.

create a md document that describes the behaviour of the component and division process.

note that this component will be shown on the map page in place of the current map when the user checks the "math" checkbox (which is to the right of the tract checkbox), and use the same step navigation to move between steps in the box component. the component grid should scale to the components container, (.map-container)

in the map page info section, display a simple explanation of what the current step just displayed.
