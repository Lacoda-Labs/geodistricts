## Public sources for state border polygons

### 1. US Census Bureau TIGER/Line (recommended)
- Source: https://www.census.gov/geographies/mapping-files.html
- Format: Shapefiles (convert to GeoJSON)
- Coverage: All 50 states + DC
- Advantages:
  - Same source as your census tracts (consistent boundaries)
  - Official, authoritative
  - Updated annually
  - Matches your TIGER tract data
- Access: Download state-level shapefiles and convert to GeoJSON

### 2. Natural Earth Data
- Source: https://www.naturalearthdata.com/
- Format: Shapefiles (convert to GeoJSON)
- License: Public domain
- Advantages: Simple, clean boundaries
- Note: May not match TIGER tract boundaries exactly

### 3. Geocode Earth (Who's On First)
- Source: https://geocode.earth/data/boundary/region/
- Format: GeoJSON
- License: Who's On First License (open)
- Advantages: Pre-converted GeoJSON, ready to use

### 4. ArcGIS Online / TIGERweb services
You're already using TIGERweb for tracts. There may be a state boundaries endpoint:
- Similar to: `https://services.arcgis.com/P3ePLMYs2RVChkJx/arcgis/rest/services/USA_States/FeatureServer/0/query`
- Format: GeoJSON via query API
- Advantages: No conversion needed, same source as tracts

### Recommendation
Use TIGER/Line state boundaries:
1. Consistency with your tract data
2. Official source
3. Exact boundary alignment
4. Annual updates

Implementation options:
- Download TIGER state shapefiles once, convert to GeoJSON, and cache
- Use an ArcGIS/TIGERweb state boundaries API endpoint if available
- Replace the Step 0 union polygon creation with a direct state boundary lookup
