## Hero Component Button Alignment Fix

### Issue
Button text and icon alignment was not centered in the hero component.

### Solution
Fixed the alignment by wrapping the button text and icon in a `span` with `flex items-center` classes. This ensures:
- Text and icon are treated as a single flex unit
- Proper vertical alignment with `items-center`
- The button component's existing `items-center justify-center` centers the span within the button

### Changes Made
**File:** `frontend/src/app/components/hero/hero.component.ts`

Wrapped the "Learn more" text and arrow icon in a flex container:
```typescript
<span class="flex items-center">
  Learn more
  <mat-icon class="ml-2 group-hover:translate-x-1 transition-transform">arrow_forward</mat-icon>
</span>
```
