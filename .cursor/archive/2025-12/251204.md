## 0035
see doc/251204-how-to-create-union-polygons.md

**Summary:**
- Implemented S4-ordered sequential merging approach as specified in the markdown document
- Added new `createUnionPolygonsS4Ordered()` function that:
  - Starts with first tract from sorted DG tracts
  - Uses S4 adjacency to merge tracts in adjacency order (not arbitrary order)
  - Tracks merged tracts in a Set to avoid duplicates
  - On merge failure, starts a new subset union polygon and continues S4 merge sequence
  - When no more adjacent tracts remain, continues with next unmerged tract from sorted list
  - After all single tracts attempted, attempts to merge subset polygons with each other and with main polygon
  - Returns one or more union polygons per DG (supports islands and geographically isolated tract groups)
- Modified `createUnionPolygonsForGroup()` to try S4-ordered approach first when adjacency graph is available
- Falls back to connected components approach if S4-ordered merging fails
- Benefits: Adjacency-first merging improves success rates, failure recovery through subset creation, incremental approach catches issues early, better handling of complex geometries
