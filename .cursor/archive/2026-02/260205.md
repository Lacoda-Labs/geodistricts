## 2216

### Prompt

1. Asked whether the `.cursor` directory is used by agents to provide context to every chat.  
2. Described a plan to persist all chat conversations: check/create `YYMMDD.md` in `.cursor/archive/YYYY-MM/`, first line `# YYMMDD`, then `## HHMM` (24h), prompt and response/action sections; no sensitive information in archives or git. Requested feedback on the plan.  
3. Requested implementation of (1) a concrete markdown template for one archive entry and (2) a short spec for a pre-commit hook (patterns to scan, where).  
4. Ran `/archive this chat` to archive this conversation.

### Response / actions

✅ **Answered**: Clarified that `.cursor/rules/` and root `.cursorrules` provide context (always or file-based); `.cursor/commands/`, `archive/`, `plans/` are not auto-injected into every chat.

✅ **Feedback on plan**: Recommended session-based archiving (e.g. “archive this chat”) rather than per-prompt auto-append (Cursor has no “on every prompt” hook). Suggested optional `### Prompt` / `### Response / actions` subsections, one file per session as an alternative if daily files get large, and pre-commit + rules for sensitive data rather than relying on the agent to redact.

✅ **IMPLEMENTED**:  
- **Template:** `.cursor/archive/ARCHIVE_ENTRY_TEMPLATE.md` — daily file path and first line, one-session structure with `## HHMM`, `### Prompt`, `### Response / actions`, minimal variant, full example, and note on sensitive info.  
- **Pre-commit spec:** `.cursor/ARCHIVE_PRE_COMMIT_SPEC.md` — purpose, when/where to scan (staged files under `.cursor/`), pattern table (API key/secret/token/password, Bearer, AWS key, GitHub PAT), what not to block, env vars (`SKIP_ARCHIVE_SECRET_CHECK`, `ARCHIVE_SECRET_CHECK_VERBOSE`), installation (copy/symlink to `.git/hooks/pre-commit`), script interface and example output.  
- **Script:** `scripts/check-archive-secrets.sh` — scans staged `.cursor/` files for those patterns, exits 1 with message on match; made executable.  
- **README:** `.cursor/README.md` — added “Archive entry format” section linking to template and pre-commit spec/script.
