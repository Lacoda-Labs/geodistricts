# Outreach Templates

This document contains templates for reaching out to experts, organizations, and state election offices.

## Email Templates

### To Election Data Experts

**Subject**: Help Needed: Voter Registration Data for Fair Districting Project

**Body**:
```
Dear [Name],

I'm reaching out because of your expertise in election data. We're working on GeoDistricts, an open-source project that uses algorithmic methods to create fair congressional districts.

To calculate party balance in districts, we need voter registration party data for all 50 states. Currently, we only have data sources for 5 states (10% complete).

We're seeking help from experts like you to:
- Identify reliable data sources for each state
- Understand data formats and access methods
- Navigate any costs or restrictions

What we need for each state:
- Precinct or county level voter registration data
- Party breakdown (Democratic, Republican, Other/Independent)
- Free or low-cost access preferred
- CSV, Excel, or API format

We've created GitHub issues for each state and would appreciate any guidance you can provide.

Project: https://github.com/Lacoda-Labs/geodistricts
State Issues: https://github.com/Lacoda-Labs/geodistricts/issues?q=is%3Aissue+label%3A%22voter-registration%22
Data Plan: https://github.com/Lacoda-Labs/geodistricts/blob/main/doc/VOTER_REGISTRATION_DATA_PLAN.md

Contributors will be recognized in project documentation and social media (with permission).

Thank you for your time and consideration.

Best regards,
[Your Name]
[Your Title]
[Contact Information]
```

## Outreach Checklist

Before sending outreach:

- [ ] Research the recipient (their work, interests, expertise)
- [ ] Personalize the message (mention specific work or connection)
- [ ] Include clear call to action
- [ ] Provide relevant links
- [ ] Make it easy to respond
- [ ] Follow up appropriately (not too soon, not too late)
- [ ] Track responses and follow-ups

## Tracking Outreach

Create a spreadsheet or document to track:

- Recipient name and organization
- Contact method (email, LinkedIn, Twitter, etc.)
- Date contacted
- Response received (yes/no)
- Outcome (helpful, not helpful, no response)
- Follow-up needed
- Notes

## Best Practices

1. **Be Respectful**: Understand people are busy
2. **Be Clear**: State what you need and why
3. **Be Appreciative**: Thank people for their time
4. **Be Persistent but Not Pushy**: Follow up, but don't spam
5. **Be Transparent**: Explain the project and goals
6. **Be Grateful**: Recognize contributions publicly
7. **Be Professional**: Use appropriate tone and language

## Response Handling

### Positive Response

- Thank them immediately
- Provide next steps
- Add them to contributor list
- Follow through on recognition

### Negative Response

- Thank them for their time
- Ask if they know anyone else who might help
- Keep the door open for future collaboration

### No Response

- Wait 1-2 weeks before following up
- Try a different contact method if appropriate
- Don't take it personally
- Move on to other contacts
