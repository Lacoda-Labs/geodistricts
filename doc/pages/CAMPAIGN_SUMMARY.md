## Quick Start Guide

### 1. Review Campaign Plan
Read the original plan: `social-media-campaign-for-voter-data.plan.md`

### 2. Launch GitHub Campaign
1. Create main issue using `.github/MAIN_CAMPAIGN_ISSUE.md`
2. Pin the issue
3. Create state-specific issues using templates from `.github/state-issues/`
4. See [Social Media Launch Guide](SOCIAL_MEDIA_LAUNCH_GUIDE.md) for details

### 3. Launch Social Media
1. Use templates from [Campaign Content Templates](CAMPAIGN_CONTENT_TEMPLATES.md)
2. Follow [Social Media Launch Guide](SOCIAL_MEDIA_LAUNCH_GUIDE.md)
3. Start with GitHub, then Twitter, Reddit, LinkedIn

### 4. Conduct Outreach
1. Use templates from [Outreach Templates](OUTREACH_TEMPLATES.md)
2. Target election data experts, state offices, researchers
3. Track outreach in spreadsheet

### 5. Maintain Engagement
1. Use templates from [Maintenance Templates](MAINTENANCE_TEMPLATES.md)
2. Post weekly updates
3. Recognize contributors
4. Track metrics using [Campaign Analytics](CAMPAIGN_ANALYTICS.md)
