# Social Media Campaign Content Templates

This document contains ready-to-use content templates for the voter registration data campaign across all platforms.

## GitHub Content Templates

### Main Campaign Issue Template

**Title**: Help Needed: Voter Registration Data for All 50 States

**Body**:
```markdown
# 🚨 Help Needed: Voter Registration Data for All 50 States

We're building **GeoDistricts**, an open-source project that uses algorithmic methods to create fair, unbiased congressional districts. To calculate party balance in districts, we need voter registration party data for all 50 states + DC.

## Current Status

- ✅ **Configured**: 5 states (AZ, CA, FL, NY, TX)
- 🔍 **Help Needed**: 46 states
- 📊 **Progress**: 10% complete

## What We Need

For each state, we need voter registration party data with:
- **Geographic granularity**: Precinct or county level (preferably precinct)
- **Data fields**: Total voters, Democratic, Republican, Other/Independent
- **Format**: CSV, Excel, or API access
- **Cost**: Free or low-cost preferred

## How You Can Help

1. **Find Data Sources**: Research your state's election office website
2. **Create an Issue**: Use our [State Data Source Request template](.github/ISSUE_TEMPLATE/data-source-request.md)
3. **Share Information**: Provide links, formats, costs, and access methods
4. **Help Implement**: Optionally help implement the data loader

## State-Specific Issues

We've created individual issues for each state. Check them out:
- [View all state issues](https://github.com/Lacoda-Labs/geodistricts/issues?q=is%3Aissue+label%3A%22voter-registration%22)

## Resources

- [Voter Registration Data Plan](doc/VOTER_REGISTRATION_DATA_PLAN.md) - Detailed requirements
- [State Data Sources Tracking](doc/STATE_DATA_SOURCES.md) - Current status
- [Contributing Guidelines](CONTRIBUTING.md) - How to contribute

## Contributor Recognition

Contributors will be recognized in:
- Project README
- GitHub contributors page
- Social media acknowledgments (with permission)

Thank you for helping make fair districting transparent! 🙏
```
