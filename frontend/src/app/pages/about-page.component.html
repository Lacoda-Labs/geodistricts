About GeoDistricts

Geodistricts are fair, unbiased congressional districts based solely on geographic and demographic data.

What is GeoDistricts?

GeoDistricts is an open-source project that uses an algorithmic approach to create fair, unbiased congressional districts. Instead of allowing humans (commissions, politicians, etc.) to draw district boundaries that favor a party (gerrymandering), GeoDistricts uses objective geographic and demographic data to automatically generate district maps.

The algorithm divides states into congressional districts based on:

  • Population equality: Districts are balanced to have nearly equal populations (target: <1% variance)
  • Geographic principles: Uses latitude and longitude divisions to ensure fair geographic distribution
  • Census data: Relies on publicly available U.S. Census Bureau data for accuracy and transparency
  • Objective methodology: No human intervention—the algorithm runs deterministically

The Problem We're Solving

Gerrymandering is the practice of manipulating electoral district boundaries to favor one political party over another. When politicians draw district lines based on voter registration data, they can create districts that guarantee their party's victory, undermining the democratic process.

The United States Constitution gives states authority to manage how they elect representatives, but this power has been abused through gerrymandering. GeoDistricts provides an objective, algorithmic solution that eliminates this manipulation.

How It Works

Our algorithm uses a hierarchical division strategy to create districts:

  • County-Level Division: First, counties are sorted geographically and divided into balanced groups by population
  • Tract-Level Refinement: Within each county group, census tracts are sorted geographically and divided to achieve precise population targets
  • Alternating Divisions: Each iteration alternates between dividing by latitude and longitude to ensure balanced geographic distribution
  • Population Balancing: The algorithm continues dividing until each district group contains exactly one district, maintaining population equality throughout

The process is fully transparent—you can view step-by-step visualizations of how districts are created for any state.

Technology

GeoDistricts is built with modern web technologies:

  • Frontend: Angular with Material Design components
  • Backend: Node.js API server
  • Data Sources: U.S. Census Bureau API and TIGER/Line shapefiles
  • Deployment: Google Cloud Run

The project is open source and available on GitHub. We welcome contributions from developers, data researchers, and anyone interested in making democracy more fair.

Data Sources

GeoDistricts uses publicly available data from trusted sources:

  • Population Data: U.S. Census Bureau API (api.census.gov)
  • Boundary Data: TIGER/Line shapefiles from the Census Bureau
  • District Counts: Official congressional district apportionments (435 total, allocated by state)
  • US congressional district boundaries (map): Jeffrey B. Lewis, Brandon DeVine, Lincoln Pitcher, and Kenneth C. Martis — congressional-district-boundaries (GitHub), MIT License.

All data is publicly available and verifiable. We do not use proprietary or private data sources.

Our Mission

Democracy works best when every vote counts equally. By eliminating gerrymandering through objective, algorithmic district creation, we aim to restore fairness to the electoral process.

No centralized state authority can be compromised into gerrymandering when districts are created by an open, transparent algorithm. This is our vision for a more democratic future.
